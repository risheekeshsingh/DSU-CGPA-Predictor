## 🚀 Project Overview

The **DSU CGPA Predictor** is a high-performance React application built using Vite and Tailwind CSS. It provides a streamlined interface for students to input their marks, credits, and previous semester SGPAs to generate accurate academic results. The design is inspired by top-tier learning platforms like Coursera and Udemy, featuring a clean, minimal, and elegant UI/UX.

## ✨ Main Features

- **SGPA Calculator:** Calculate Semester Grade Point Average based on CIA and SEE marks.
- **CGPA Predictor:** Predict overall Cumulative Grade Point Average by entering SGPAs of multiple semesters.
- **Auto-Calculations:** Real-time updates as you type your marks or credits.
- **Responsive Design:** Fully optimized for Desktop, Tablet, and Mobile devices.
- **Premium UI:** Glassmorphism effects, smooth hover animations, and professional color palette.
- **DSU Grade System:** Integrated logic following the specific grading standards of DSU.

## 💻 Installation & Local Setup

To run this project locally, follow these steps:

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/risheekeshsingh/DSU-CGPA-Predictor.git
cd DSU-CGPA-Predictor
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
The app will be available at `http://localhost:5173`.

## 🏗️ Build & Deployment

### Build for Production
To generate an optimized production build:
```bash
npm run build
```
The output will be in the `dist/` directory.

### Deployment on Netlify
This project is pre-configured for Netlify with a `netlify.toml` file.
1. Connect your GitHub repository to Netlify.
2. Netlify will automatically detect the build settings:
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`
3. Enjoy your live site!
