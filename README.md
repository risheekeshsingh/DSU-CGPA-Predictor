## 🚀 Project Overview

The **DSU CGPA Predictor** is a high-performance React application built using Vite and Tailwind CSS. It provides a streamlined interface for students to input their marks, credits, and previous semester SGPAs to generate accurate academic results. The design features a clean, minimal, and elegant UI/UX with glassmorphism effects and smooth animations.

---

## ✨ Main Features

- 🎯 **SGPA Calculator** — Calculate Semester Grade Point Average based on CIA and SEE marks
- 📈 **CGPA Predictor** — Predict overall Cumulative Grade Point Average by entering SGPAs of multiple semesters
- ⚡ **Auto-Calculations** — Real-time updates as you type your marks or credits
- 📱 **Responsive Design** — Fully optimized for Desktop, Tablet, and Mobile devices
- 💎 **Premium UI** — Glassmorphism effects, smooth hover animations, and professional color palette
- 🎓 **DSU Grade System** — Integrated logic following the specific grading standards of Dayananda Sagar University
- 👤 **Creator Profiles** — Meet the team section with profile photos
- 🌙 **Modern Aesthetics** — Dark-themed premium interface with gradient accents

## 💻 Installation & Local Setup

To run this project locally, follow these steps:

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** (v9 or higher)

### 1. Clone the Repository
```bash
git clone https://github.com/risheekeshsingh/DSU-CGPA-Predictor.git
cd DSU-CGPA-Predictor
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
The app will be available at `http://localhost:5173`

---

## 🏗️ Build & Deployment

### Build for Production
```bash
npm run build
```
The optimized output will be in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```

### Deploy to Netlify
This project is pre-configured for Netlify via `netlify.toml`.

1. Connect your GitHub repository to [Netlify](https://netlify.com)
2. Netlify auto-detects the build settings:
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`
3. Click **Deploy** — your site goes live instantly! 🚀
